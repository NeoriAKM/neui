DOCUMENTATION NeUI (Not User Interface)

1. How to begin?

Begin with importing neui

```
import neui
```

and class defining

```
root = neui.Draw(delay=10, width=20, height=18)
# shorter
root = neui.Draw(10, 20, 18)
```

all is ready. You can make some objects  now. They making with a
`root.add((x, y, symbol, id))`. x,y - coo. symbol - symbol whats you
drawing every frame in field, and id - its.... ID of object.
He's want to be unique. please note, root.add has
2 bracked.

Next, make `run = True; while run:`, its mainloop. Add here
`root.draw()`, he is drawing frame. Ready. Your object will be
drawn of screen 20x18 pixels. You can delete him (root.remove(ID))
or move (root.move(id, x, y), x & y - new poses. From obj you
need Only ID)


2. How to make widget?

Widgets - Thats trinkets on left/right side. They can show
simple text, score, or any other info. Be like:
var f"{root.getinfo(1, 2)} = {root.getinfo(1, 0)}/{root.getinfo(1, 1)}"

(more about getinfo on 3rd point)

root.getinfo(1, 2) - from ID 1 reading 2 value of cortege. 2 value is sym
root.getinfo(1, 0) - from obj с ID 1 reading 0 value, it is a coo x
root.getinfo(1, 1) - its the same, но 1 value is coo y

Widget adding with function root.add_ui((left_or_right_0_or_1, y, content, UI_ID)).
Note: ID and UI-ID its 2 different things.
Note2: Widget you can make only 1 times, and it is will not be in mainloop.
In the while run you will need add root.update_ui, about him described in 3 point.



3. More abt functions

root.getinfo(ID, Index_in_cortege): ID is ID. Index - element from cortege.
0 - x, 1 - y, 2 - sym, 3 - ID (but for what?)

root.update_ui(content, id): content - place thats you need update. If content has var x,
type root.update(x, {id}).

root.isempty(x, y): returns True if cell x,y occupied, and False if non-occupied.

root.endsession(): Ending session. optionally you can type end msg
be like root.endsession("Bye bye!")


4. Variables

Yeah, you can change vars values in session working time.

root.w / root.h: width, height of field

self.tact: delay to update field.

There us little that can be changedm, but thats only beta version.
