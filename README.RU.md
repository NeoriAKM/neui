### Наипростейший фреймворк для создания интерфейса в терминале.

Я сделал суперлегкий фреймворк для создания игр в консоли. Если вам это нужно - передвиньте или скопируйте файл `ntui.py` в ваш проект, и импортируйте neui, типа:

```python
import neui
# imports

run = True
while run:
    # ваш код
    # ...
```


**Не имеет зависимостей**. Кроме как `Python 3.4` и новее. **Используемые модули** - `os, time`

**Примеры кода** - [game.py](1) , [game2.py](2) , [game3.py](3)
