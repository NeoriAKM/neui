# Документация NeUI (Not User Interface)

[English doc link](documentation.md)

## 1. Как начинать?

Начинать стоит с **импортирования neui**

```python
import neui
```

и **определения класса**

```python
root = neui.Draw(delay=10, width=20, height=18)
# или короче
root = neui.Draw(10, 20, 18)
```

Всё готово. Теперь можете создать пару объектов. **Они создаются с помощью** `root.add((x, y, symbol, id))`. **Поясняю**: x,y - координаты. symbol - это символ которым и будет отображаться объект, и id - это айди объекта. ID Должен быть уникальным. 
> **Обратите внимание на то что root.add имеет 2 скобки. Это обязательно.**

Далее создадите `run = True; while run:` и там будет дальнейшее. Как например - root.draw(), он рисует кадр. Готово. Ваш объект должен отображаться на экране 20x18 пикселей. Вы можете его удалить (`root.remove(айди_объекта)`) или переместить (`root.move(айди, x, y)`, x & y - новые позиции. *От объекта вам нужен **только ID***)


## 2. Как сделать виджет?

***виджеты - это штучки слева или справа*. Они могут отображать простой текст, очки, или любую другую информацию**. Например:

переменная `f"{root.getinfo(1, 2)} = {root.getinfo(1, 0)}/{root.getinfo(1, 1)}"`

щас разберем:

*(больше про getinfo в 3 пункте)*

- `root.getinfo(1, 2)` - это он из ID 1 читает 2 значение кортежа. 2 значение это символ
- `root.getinfo(1, 0)` - из объекта с ID 1 читает 0 значение, это координата x
- `root.getinfo(1, 1)` - это то же самое, но 1 значение это координата y

**Виджет создается функцией** `root.add_ui((лево_или_право_0или1, y, контент, UI_ID))`.
> **Важно**: ID и UI ID это разные вещи.
> **Важно**: Виджет надо создавать 1 раз, то есть он не должен быть в while run.

В while run должен быть `root.update_ui`, **о котором написано в 3 пункте**


## 3. Подробнее про функции

### 3.1 функция `root.getinfo(айди, индекс_в_кортеже)`
**айди** это айди. **Индекс** - это элемент из кортежа информации.
- 0 - x
- 1 - y
- 2 - отображаемый символ
- 3 - айди (но нафиг?)

### 3.2 `root.update_ui(content, id)`
**контент** - туда ставьте то что хотите обновить.

### 3.3 `root.isempty(x, y)`:
**возвращает True** если клетка x,y занята, и **False** если пуста.

### 3.4 `root.endsession()`:
заканчивает. И ещё можно ввести прощальное сообщение, но это опционально. Например `root.endsession("Пока!")`


## 4. Переменные

Да, вы можете прямо во время сессии менять значения.

- **root.w / root.h**: ширина и длина поля

- **self.tact**: раз в сколько мс будет обновляться поле.

> Признаю, изменить можно мало, но это только бета версия.
